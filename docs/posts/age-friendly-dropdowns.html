Age-Friendly Dropdowns

Well‑designed dropdowns help people choose quickly without guessing. For older adults, small missteps compound: tiny targets, surprise scroll jumps, hidden keyboard focus, and long ungrouped lists all raise the effort.

What makes a dropdown age‑friendly?

  • Clear, descriptive label above the control
  • Large click target with generous spacing
  • Keyboard support (Arrow keys, Home/End, type‑ahead)
  • Visible focus ring and open state
  • Grouped options with separators and headers
  • No auto‑scrolling the page when opening

Common pitfalls

  1. Placeholder text that looks like a selection
  2. 30+ ungrouped items with no search
  3. Disabling the label and relying on placeholder
  4. Confusing custom components that break native affordances

Practical checklist

  • Use native <select> when it meets needs; enhance progressively
  • Keep labels visible at all times
  • Provide search for long lists; otherwise, use alphabetic grouping
  • Preserve selection on blur; allow easy correction
Inclusive design is good design. Improving dropdowns for older adults benefits everyone.
